# Changelog

## Unreleased

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.

Extracted from `github.com/youruser/goorm/auth/strategies/oauth2util` and turned into a full-fledged
strategy.

### Breaking
- Module path is now `github.com/shibisty/passport.go-oauth2-strategy`, package `oauth2`.
- `oauth2.New(name, Config, ProfileMapper)` replaces the set of functions.

### Added
- `AuthParams`, `Config()`, `Exchange`, `FetchUserInfo`, helpers `String` and `Bool`.
- Errors `ErrAccessDenied`, `ErrMissingCode`, `ErrNoUserID`.
- `oauth2test` package: a fake provider for tests.
- Tests.

### Fixed
- HTTP request timeout (15 s) instead of `http.DefaultClient` with no timeout.
- Limits on the provider response size (1 MB) and the error message text (512 bytes).
- The `error` parameter in the callback is handled before the code exchange.
- `AuthURL` with existing query parameters (`?tenant=…`) no longer breaks.
