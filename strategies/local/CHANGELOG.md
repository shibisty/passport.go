# Changelog

## Unreleased

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.

Extracted from `github.com/youruser/goorm/auth/strategies/local`.

### Breaking
- Module path is now `github.com/shibisty/passport.go-local-strategy`.
- `ErrInvalidCredentials` is an alias for `passport.ErrInvalidCredentials`.

### Added
- `WithFields` for custom field names.
- Tests.

### Fixed
- The email is trimmed; empty fields are rejected before `VerifyFunc` is called.
