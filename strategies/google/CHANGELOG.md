# Changelog

## Unreleased

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.

Extracted from `github.com/youruser/goorm/auth/strategies/google`.

### Breaking
- Module path is now `github.com/shibisty/passport.go-google-strategy`.
- `google.New` returns `*oauth2.Strategy` from `passport-oauth2`.

### Added
- `Identity.EmailVerified` from `email_verified`.
- Options `WithScopes`, `WithHTTPClient`, `WithEndpoints`, `WithAuthParam`; `MapProfile`.
- Tests against a fake provider.
