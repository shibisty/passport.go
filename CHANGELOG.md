# Changelog

## Unreleased

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.

Package extracted from the template `github.com/youruser/goorm/auth`.

### Breaking
- Module path is now `github.com/shibisty/passport.go`; Go package `auth` → `passport`.
- Strategies moved to separate repositories: `passport-local`, `passport-oauth2`,
  `passport-google`, `passport-facebook`; Redis sessions: `passport-session-redis`.
- `auth/token/jwt` → `passport/jwt`; `jwt.New` returns `(*Issuer, error)` and requires
  a secret of at least 32 bytes.
- `auth/sessionstore/memory` → `passport/memorystore`.
- `passwordhash` moved here from orm (`passport/passwordhash`); new hashes use 600,000
  iterations (was 100,000). Old hashes still verify; `NeedsRehash` tells you when to recompute.
- `SessionStore.Get`: a missing session yields `ErrSessionNotFound`; other errors
  are returned as is.

### Added
- `Identity.EmailVerified`; `Identity.Raw` is not serialized.
- `ErrInvalidCredentials` in the core (strategies use the same error).
- `jwt`: validation of `alg`, `iss`, `nbf`; `WithLeeway`, `WithClock`.
- `passwordhash.NeedsRehash`, `ErrInvalidHash`, parameter limits when parsing a hash.
- `httpauth.NewState` / `CheckState` (OAuth2 CSRF protection), `WithIdentity`.
- `sessionstoretest`: a shared test suite for session stores.
- Tests for the entire core.

### Fixed
- `Authenticator` is safe for concurrent use.
- `httpauth.Middleware` accepts the `Bearer` scheme in any case.
- `memorystore` deletes expired sessions instead of merely hiding them.
